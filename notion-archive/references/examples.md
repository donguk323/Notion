# 블록 모양별 예시

예시의 내용은 아카이브의 실제 글에서 가져왔다. 실제 저장할 때는 대화와 원문에 있는 값만 쓴다.
예시와 SKILL.md가 다르면 SKILL.md를 따른다. 노션 문법의 세부는 `notion-format.md`에 있다.

## 첫 화면 — 고르기 글

```
<callout icon="🎯" color="blue_bg">
	**1. 일반 문서·웹·AI 작업용 모니터로 Dell S2725QC를 추천한다. 아직 정하지 않았다.**
	이미 허브·스피커가 있고 가격이 1순위면 AOC U27G4가 낫다.
	맥미니 M6에 직접 연결해 본 결과는 없다.
	구매 직전에 같은 판매 화면에서 현재 가격·배송·교환 조건을 확인한다.
</callout>
맥락: 왜 맥미니 M6용 모니터 한 대 · 기준일 2026-10-05 {color="gray"}
```

- 판단(굵게) → 조건 → 근거 강도 → 행동 순서다.
- 할 일이 하나라 할 일 목록 없이 행동 칸에 썼다.

## 첫 화면 — 판단이 없는 클리핑

```
<callout icon="🎯" color="blue_bg">
	**1. 모션그래픽 용어 21개와 짧은 뜻, 제작 요청 문구를 모았다.**
</callout>
맥락: 출처 사용자가 준 이미지 1장(2026-10-04) {color="gray"}
```

## 왜 그런가? → 소결론 · 이유 · 근거

```
## 정비 문서 — 쉬운 말보다 "한 개념에 한 이름"이 핵심이다
같은 부품을 여러 이름으로 부르면 작업자가 같은 대상인지 다시 따져야 한다.
- FAA 정비 지침은 같은 부품을 다른 이름으로 부르는 것을 오류 원인으로 꼽는다.
- 예: start·begin·commence를 섞지 않고 승인된 한 단어만 쓴다.
```

## 어떻게 하나? → 번호 단계

```
## 설치 — 외장 SSD에 macOS를 깔고 기존 환경을 옮긴다
1. 기존 자료를 다른 저장 장치에 백업한다.
2. 외장 SSD를 DFU 포트가 아닌 포트에 연결한다.
**주의:** 지우기 전에 장치 이름과 용량을 대조해 내장 디스크를 고르지 않는다.
3. 디스크 유틸리티에서 외장 SSD를 GUID 파티션 맵·APFS로 지운다.
4. 외장 SSD를 설치 위치로 골라 macOS를 설치한다.
```

- 한 줄에 행동 하나. 주의 문장은 지우기 단계(3번) 바로 앞이다.

## 무엇인가? → 뜻 · 원리 · 예시 · 오해

```
## 스왑 — RAM이 바쁠 때 일부 내용을 저장 장치로 잠시 옮기는 방법이다
macOS는 RAM에 계속 둘 필요가 없는 내용을 시동 디스크로 옮겼다가 필요할 때 다시 가져온다.
비유하면 RAM은 작업대, 저장 장치는 보관 서랍이다. 작업대가 꽉 차면 일부를 서랍에 넣어 둔다.
흔한 오해: 외장 SSD로 부팅하면 RAM이 늘어난다. 저장 공간만 늘고 RAM은 그대로다.
```

## 경험담 블록

```
## 원글 — 외장 부팅 뒤 쾌적해졌다는 한 사람의 경험이다
아래는 글쓴이 한 사람의 경험이다. 측정값은 없다.
- 맥미니 M4 기본형에서 스왑 때문에 저장 공간이 줄었다고 한다.
- 외장 SSD에 macOS를 설치하고 옮기는 데 몇 시간이 걸렸다고 한다.
- 이후 쾌적해졌다고 한다.
쾌적해진 이유가 스왑 때문인지는 확인하지 못했다.
```
