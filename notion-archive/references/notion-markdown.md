# 노션 렌더 규칙 (Notion MCP enhanced markdown)

## 목차
- 들여쓰기와 빈 줄
- 콜아웃
- 토글
- 인용 블록
- 표
- 색
- 다른 페이지 가리키기
- 이스케이프
- 긴 본문 적재

기준: Notion MCP의 `notion://docs/enhanced-markdown-spec`. 문법이 의심스러우면 저장 전에 그 문서를 `fetch`로 다시 읽는다.

## 들여쓰기와 빈 줄

- 자식 블록은 **탭**으로 들여쓴다. 공백 들여쓰기는 자식으로 인식되지 않을 수 있다.
- 빈 줄은 저장할 때 사라진다. 노션이 블록 간격을 알아서 준다. 정말 빈 줄이 필요하면 `<empty-block/>`을 한 줄에 단독으로 쓴다. 이 스킬에서는 거의 쓸 일이 없다.

## 콜아웃

```
<callout icon="🎯" color="green_bg">
	**굵은 첫 줄**
	둘째 줄
</callout>
```

- 이 스킬의 용도는 셋뿐이다. 🎯 결론(`green_bg`), ⚠️ 함정 하나(`pink_bg`), 필요하면 🔥 지금 할 일(`yellow_bg`). 콜아웃이 넷 이상이면 첫 화면이 다시 시끄러워진다.
- 콜아웃 안의 서식은 HTML이 아니라 마크다운(`**굵게**`)으로 쓴다.
- 콜아웃을 지원하지 않는 클라이언트라면 인용 블록 하나에 `<br>`로 줄을 나눠 같은 세 줄을 넣는다.

## 토글

```
<details>
<summary>🗑️ 뺀 것</summary>
	- 후보 A — 이유
</details>
```

- 내용 줄을 탭으로 들여쓰지 않으면 토글 밖으로 빠진다.
- 제목형 토글도 된다: `## 제목 {toggle="true"}` 다음 줄부터 탭 들여쓰기.

## 인용 블록

- 한 인용 블록에 여러 줄을 넣을 때는 `<br>`을 쓴다: `> 첫 줄<br>둘째 줄`
- `>`를 줄마다 쓰면 서로 다른 인용 블록 여러 개가 된다.

## 표

```
<table header-row="true">
	<tr><td>항목</td><td>값</td></tr>
	<tr><td>A</td><td>1</td></tr>
</table>
```

- 셀 안에는 글자만 넣는다. 목록·제목·이미지는 들어가지 않는다. 셀 안 서식도 HTML 태그 대신 `**굵게**`로 쓴다.
- 3~4열까지만 쓴다. 넘으면 표를 둘로 나누거나 열을 줄인다.
- 강조할 행은 `<tr color="green_bg">`로 칠할 수 있다. 추천 행 하나에만 쓴다.
- 셀 병합은 문법으로 못 만든다. 필요하면 사용자에게 노션 화면에서 하라고 알린다.

## 색

- 글자색: `gray, brown, orange, yellow, green, blue, purple, pink, red`
- 배경색: 위 이름에 `_bg`를 붙인다.
- 블록 전체: 줄 끝에 `{color="gray"}`. 부분: `<span color="yellow_bg">…</span>`
- 이 스킬에서는 맥락 줄의 회색과 콜아웃 배경 정도만 쓴다. 본문 형광펜은 결론 문장 하나까지만 칠한다. 다 칠하면 아무것도 강조되지 않는다.

## 다른 페이지 가리키기

- **`<mention-page url="…"/>`** 는 링크만 건다. 관련 문서를 가리킬 때는 항상 이것을 쓴다.
- **`<page url="…">`** 는 기존 페이지를 **이 페이지의 하위 페이지로 옮긴다.** 반대로 기존 `<page>` 태그를 지우면 그 하위 페이지가 사라진다. 갱신할 때 본문을 통째로 바꾸다가 이 태그를 지우지 않도록 조심한다.
- DB는 `<mention-database url="…"/>`로 가리킨다. `<database url="…">`도 DB를 옮긴다.
- 외부 링크는 `[제목](URL)`로 쓴다.

## 이스케이프

본문 글자로 다음 문자를 쓸 때는 앞에 `\`를 붙인다: 역슬래시, `*`, `~`, 백틱, `$`, `[`, `]`, `<`, `>`, `{`, `}`, `|`, `^`. 범위 표기의 물결표도 대상이다(예: `3\~5만`, `9/1\~9/14`). 코드 블록 안은 이스케이프하지 않는다.

## 긴 본문 적재

- 한 번에 넣기 어려우면 결론 블록·맥락 줄·핵심까지 먼저 만들고, 나머지 절은 `insert_content`로 이어 붙인다.
- 기존 페이지를 고칠 때는 `replace_content`보다 `update_content`의 찾아 바꾸기를 쓴다. 전체 교체는 하위 페이지·DB 블록을 지울 위험이 있다.
- 적재가 끝나면 페이지를 다시 조회해 마지막 절(🔗 출처)까지 들어갔는지 확인한다.
