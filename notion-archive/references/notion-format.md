# 노션 문법 (Notion MCP enhanced markdown)

기준은 노션의 `notion://docs/enhanced-markdown-spec`이다. 문법이 의심스러우면 저장 전에 그 문서를 조회 도구로 다시 읽는다.
이 파일은 SKILL.md의 요소를 노션 문법으로 옮기는 방법만 다룬다. 무엇을 쓸지는 SKILL.md가 정한다.

## 첫 화면

```
<callout icon="🎯" color="blue_bg">
	**1. ○○를 추천한다. 아직 정하지 않았다.**
	○○이면 결론이 바뀐다.
	**2. ○○는 △△다.**
</callout>
맥락: 누가 ○○ · 왜 ○○ · 기준일 2026-10-09 {color="gray"}
용어: ○○ = 쉬운 말 한 구절 {color="gray"}
- [ ] 가장 먼저 할 일. 계약 전.
- [ ] 그다음 할 일. 첫 사용 전.
```

- 결론 상자는 콜아웃 하나, `icon="🎯" color="blue_bg"`로 고정한다. 다른 콜아웃은 만들지 않는다.
- 결론마다 판단 문장만 굵게 쓴다. 조건·근거 강도·행동 문장은 굵게 쓰지 않는다.
- 콜아웃 안의 줄은 **탭**으로 들여쓴다. 안 하면 콜아웃 밖으로 빠진다.
- 콜아웃 안 서식은 HTML이 아니라 마크다운(`**굵게**`)으로 쓴다.

## 본문

- 소제목: `## 연결 — 맥미니 뒤쪽 포트에 바로 꽂는다`. 필요하면 `###`로 한 단계 더 나눈다.
- `##` 블록 사이에는 구분선 `---`을 둔다.
- 번호 단계: `1. `, 할 일: `- [ ] `.
- 주의 문장: 그 주의가 걸린 단계 바로 앞 줄에 `**주의:** ○○하기 전에 △△한다.`
- 회색 한 줄(표·그림 설명): 줄 끝에 `{color="gray"}`.
- 원문 핵심 한 문장 인용: `> 원문` . 한 인용에 여러 줄이면 `<br>`로 잇는다. `>`를 줄마다 쓰면 인용 블록이 여러 개가 된다.

## 표

```
<table header-row="true">
	<tr color="blue_bg"><td>후보</td><td>가격</td><td>판단</td></tr>
	<tr color="green_bg"><td>A</td><td>514,000원</td><td>추천</td></tr>
	<tr><td>B</td><td>419,000원</td><td>가격 대안</td></tr>
</table>
```

- 헤더 행만 `blue_bg`. 추천 행 하나만 `green_bg`. 그 밖의 행은 칠하지 않는다.
- 셀 안에는 글자와 `**굵게**`만 넣는다. 목록·제목·이미지는 들어가지 않는다.
- 셀 병합은 문법으로 못 만든다.

## 그림

**머메이드**
````
```mermaid
flowchart LR
	A["결론 (BLUF)"] --> B["이유 (PREP)"] --> C["문장 (통제언어)"]
```
````
- 특수문자가 든 노드 이름은 큰따옴표로 감싼다. 줄바꿈은 `<br>`. 코드 블록 안은 이스케이프하지 않는다.

**HTML 임베드** (첨부 만들기 도구가 있을 때만)
1. 첨부 만들기 도구(create-attachment)로 HTML 파일을 만든다.
2. 돌려받은 `file-upload://` 주소를 `<embed src="file-upload://…">이 그림이 보여 주는 것</embed>`로 본문에 넣는다.
3. HTML 첨부는 코드 블록이나 파일 블록으로 넣지 않는다. 항상 `<embed>`로 넣는다.

## 접기

```
<details>
<summary>고르지 않은 이유</summary>
	- **AOC U27G4** — USB-C 없음. 이미 허브가 있고 가격이 1순위면 이긴다.
</details>
```

- 내용 줄을 탭으로 들여쓰지 않으면 접기 밖으로 빠진다.
- `출처`도 접기로 둔다. 맨 아래 `조사 원자료`는 접기 하나로 둔다.
- 원자료가 문서 몇 개 분량이면 하위 페이지를 만든다. 하위 페이지 태그 `<page>`는 지우면 그 페이지가 사라진다. 고칠 때 이 태그를 지우지 않는다.

## 다른 페이지 가리키기

- 관련 글은 `<mention-page url="…"/>`로 가리킨다. 링크만 건다.
- `<page url="기존 페이지">`는 그 페이지를 이 페이지 밑으로 **옮겨 버린다.** 가리킬 때 쓰지 않는다.
- DB는 `<mention-database url="…"/>`. `<database url="…">`도 DB를 옮긴다.
- 외부 링크는 `[제목](URL)`.

## 이스케이프와 자동 링크

- 본문 글자로 쓸 때 앞에 `\`를 붙이는 문자: 역슬래시, `*`, `~`, 백틱, `$`, `[`, `]`, `<`, `>`, `{`, `}`, `|`, `^`. 범위의 물결표도 대상이다(`9\~18시`). 코드 블록 안은 예외다.
- 점이 든 파일명·도메인(`SKILL.md`, `claude.ai`)은 백틱으로 감싼다. 안 감싸면 노션이 가짜 링크로 바꾼다.
- 빈 줄은 저장할 때 사라진다. 블록 간격은 노션이 알아서 준다.

## 긴 본문 적재

- 한 번에 넣기 어려우면 첫 화면과 앞쪽 블록을 먼저 만들고, 나머지를 이어 붙인다.
- 기존 페이지를 고칠 때는 찾아 바꾸기(update_content)를 쓴다. 본문 전체 교체(replace_content)는 하위 페이지·DB 블록을 지울 수 있다.
- 적재가 끝나면 페이지를 다시 조회해 마지막 접기까지 들어갔는지 확인한다.
