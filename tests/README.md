## 판정 방법 (사용자)

원고마다 **첫 화면(제목·결론 상자·회색 줄)만** 보고 세 가지를 적는다.

1. 결론을 한 줄로
2. 결론이 뒤집히는 조건
3. 처음 멈칫한 곳 (없으면 "없음")

02·03·04는 옛 페이지도 같은 방식으로 본다. 새 판이 더 빨리, 더 정확하게 읽히는지 비교한다.

## 원고를 쓰며 바꾼 규칙

- **판단 문장 형태를 4개에서 5개로 늘렸다.** 보고서·개념 글처럼 "알게 된 것을 정리한 글"은 누가 정했는지를 따질 판단이 없다. 그래서 "알게 된 사실을 평서문 한 문장으로"를 더했다.
- **판단 칸에 풀어 주는 문장 하나를 허용했다.** "PREP와 BLUF는 경쟁 기법이 아니다"는 그 문장만으로 뜻이 서지 않아서다.
- **맥락 줄 이름표에 `출처`를 더했다.** 외부 문서나 이미지를 정리할 때 출처가 맥락의 핵심이라서다.
